Technical notes from my journey into offensive security.

I document what I investigate, how I approach a problem, what the evidence
shows, and what I learn along the way. The goal is to understand the
underlying vulnerability, not simply reproduce a sequence of commands.

## Areas of Focus

### Web Application Security

Exploring authentication, authorization, input handling, API security,
and common web vulnerabilities in authorized environments.

### Network & System Security

Documenting service enumeration, Linux and Windows security,
misconfigurations, and privilege-escalation techniques.

### Methodology

Each writeup aims to explain the objective, enumeration process,
technical reasoning, validation, impact, and relevant remediation.

---

*Only authorized labs and systems are tested. Sensitive information,
real credentials, and unauthorized targets are not published.*
