## Overview

A personal project focused on building a password manager while learning and applying secure software development principles.

The goal is to explore how sensitive credentials can be stored, protected, and managed, with an emphasis on security rather than simply implementing features.

## Objectives

- Design a simple and maintainable password management application.
- Explore encryption and key management.
- Implement secure handling of stored credentials.
- Apply input validation and appropriate error handling.
- Test the application and document security limitations.

## Security Considerations

### Password Protection

Investigate appropriate ways to protect the master password and stored credentials. Avoid storing passwords in plaintext or treating encryption alone as sufficient security.

### Encryption and Key Management

Explore authenticated encryption, secure key derivation from a master password, and the risks of insecure key storage or hardcoded secrets.

### Application Security

Consider input validation, sensitive-data exposure, dependency security, error handling, and protection against accidental disclosure of credentials.

### Testing

Plan tests for authentication, encryption and decryption, invalid inputs, incorrect master passwords, and unexpected application states.
